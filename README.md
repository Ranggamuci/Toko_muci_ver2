# MUCI ATK & PRINT
Website katalog ATK & layanan percetakan yang siap di-host di GitHub Pages.

## Fitur
- Desain modern/elegan dan responsive
- 200+ item katalog ATK
- Pencarian dan filter kategori
- Tombol pesan via WhatsApp
- Layanan fotocopy, print, cetak foto, jilid, laminating, stempel, ID card, scan
- Dark mode
- Galeri lokal tanpa ketergantungan gambar eksternal
- Fallback gambar jika aset tidak tersedia

## Menjalankan
Buka `index.html` atau upload seluruh folder ke repository GitHub, lalu aktifkan GitHub Pages.

## Mengubah produk dan harga
Edit array `products` di `script.js`.

Format:
`['Nama Produk','Kategori','Harga','assets/images/products/namafile.svg']`

Harga di paket ini adalah **contoh** dan harus disesuaikan dengan harga toko.

## Mengganti gambar
Masukkan gambar sendiri ke `assets/images/` lalu ubah path pada `script.js` atau `index.html`.
Untuk website bisnis, gunakan foto milik sendiri atau aset yang memiliki lisensi penggunaan komersial.
